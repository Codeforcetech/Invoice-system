# 入金記録と過去の請求書プレビュー

請求書一覧に入金状況のフィルターとプレビューボタンを追加。請求日・取引先などの検索条件を保持したまま帳票を開閉できる。帳票は保存済み請求内容と現在の自社設定から再生成する（過去に送ったPDFの不変アーカイブではない）。

発行済みの請求書は詳細・編集画面から全額の入金日を手動記録・訂正・取消可能。銀行の自動照合、一部入金、返金履歴には未対応。売上グラフは従来どおり請求日基準で、入金額のグラフではない。自分から相手への支払いは既存の支払管理で記録する。

`Invoice.receivedDate` のみを追加する非破壊的な移行。既存レコードは NULL（未入金・未確認）となり、実際の未入金と断定しない。過去の支払いを確認してから記録する。既存アカウント・金額・明細を変更する移行は含まない。

全変更は認証済み所有者のみ、発行済み・更新日時一致を条件に更新する。古い画面や同時操作は拒否。入金済みの請求内容はサーバーでも編集を禁止し、複製時は入金記録を引き継がない。

本番反映時には先にバックアップを取得し、`20260917100000_invoice_receipts` を含む未適用移行を適用してから新コードを公開する。ロールバック時は追加カラムを残す。今回本番DBへの操作は行っていない。
