# 請求書の管理・作成をさらに改善する案

今回、番号・会社名・件名の横断検索、更新順の一覧、下書き再開の絞り込み、送信前の確認、添付PDFの事前確認を追加した。

次の改善は、以下の順が効果的。

1. 入金管理: 「未入金／一部入金／入金済み」を発行状態と別に持つ。入金日・金額・メモを登録し、支払期限が過ぎた未入金分だけを強調する。現状には入金記録がないため、期限超過を自動的に未入金と決めつけない。
2. 毎月の請求を再利用: 既存の複製に加え、取引先別の定期テンプレートと請求月の一括更新を用意する。自動送信は行わず、作成・確認までにする。
3. 発行・送信履歴: 請求書の版、PDF生成時刻、Gmail下書き作成と手動の送信済み記録を分けて残す。Gmail下書き作成だけで送信済みにしない。実際の送信を自動検知する場合は追加のGoogle権限と運用設計が必要。
4. 経理の一覧作業: 対象月フィルター、複数PDFの一括ダウンロード、CSV出力を追加する。CSVは数式インジェクション対策を設計に含める。

いずれもDB・運用に関わる拡張なので、今回のGmail下書き機能と混ぜて自動的には実装していない。
